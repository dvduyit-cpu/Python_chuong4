CHƯƠNG 4 – HÀM, MÔ-ĐUN, GÓI; PEP 8 VÀ TYPE HINTS

Thời gian: 8 giờ

Mạch kiến thức: đoạn code lặp lại → hàm; nhiều hàm liên quan → module; nhiều module liên quan → package; toàn bộ code được viết rõ ràng bằng docstring, type hints và PEP 8.
Cách giảng: mỗi khái niệm trong bản này chỉ xuất hiện một lần. Phần lý thuyết được mở rộng từ khái niệm → lý do dùng → cách hoạt động → khi nào nên dùng → ví dụ. Các đoạn code đều có chú thích giải thích gần như từng bước, và có kết quả chạy ngay bên dưới để sinh viên đối chiếu.

1. HÀM – KHÁI NIỆM, CÁCH HOẠT ĐỘNG VÀ CÁCH DÙNG

1.1. Hàm là gì?

Hàm là một nhóm câu lệnh được đặt tên để thực hiện một nhiệm vụ cụ thể. Khi cần thực hiện nhiệm vụ đó, ta chỉ cần gọi tên hàm thay vì viết lại toàn bộ đoạn code.

Ví dụ, nếu chương trình cần tính điểm trung bình cho nhiều sinh viên, thay vì viết công thức tính trung bình ở nhiều nơi, ta tạo một hàm calculate_average() và gọi lại mỗi khi cần.

Cách giải thích cho sinh viên: có thể xem hàm như một “máy xử lý”. Ta đưa dữ liệu vào máy, máy xử lý, sau đó cho ra kết quả. Phần dữ liệu đưa vào là tham số, phần kết quả trả ra thường dùng return.

1.2. Vì sao nên dùng hàm?

  • Giảm lặp code: một đoạn xử lý chỉ viết một lần.
  • Dễ đọc: tên hàm cho biết chương trình đang làm gì.
  • Dễ sửa: thay đổi logic tại một chỗ.
  • Dễ kiểm thử: có thể chạy thử từng hàm riêng.
  • Dễ tái sử dụng: một hàm có thể được gọi nhiều nơi hoặc import sang file khác.

1.3. Cú pháp định nghĩa hàm

# Dùng từ khóa def để bắt đầu định nghĩa một hàm
# greet là tên hàm
# () là nơi khai báo tham số nếu có
def greet():
    # Các dòng thụt vào 4 khoảng trắng thuộc về hàm
    print("Xin chào")


# Định nghĩa hàm chưa làm hàm chạy
# Phải gọi hàm bằng tên hàm kèm ()
greet()
Kết quả chạy:
Xin chào

1.4. Python chạy hàm như thế nào?

  1. Python đọc dòng def greet(): và ghi nhớ hàm.
  2. Python chưa chạy lệnh print() bên trong ngay.
  3. Khi gặp greet(), Python đi vào hàm.
  4. Python thực hiện các lệnh trong hàm từ trên xuống.
  5. Khi hàm kết thúc, Python quay lại dòng sau nơi gọi hàm.

1.5. Hàm có tham số

Tham số giúp một hàm xử lý được nhiều dữ liệu khác nhau.

# name là tham số
# Mỗi lần gọi hàm, name có thể nhận một giá trị khác nhau
def greet(name):
    # Dùng f-string để ghép giá trị name vào chuỗi
    print(f"Xin chào {name}")


# "An" được truyền vào tham số name
greet("An")

# "Bình" được truyền vào tham số name ở lần gọi tiếp theo
greet("Bình")
Kết quả chạy:
Xin chào An
Xin chào Bình

1.6. Hàm không có return và hàm có return

Một hàm có thể chỉ thực hiện hành động, ví dụ in ra màn hình. Nhưng nếu muốn lấy kết quả để dùng tiếp, ta cần return.

# Hàm này chỉ hiển thị kết quả
def show_sum(a, b):
    print(a + b)


# Hàm này trả kết quả về nơi gọi
def calculate_sum(a, b):
    return a + b


show_sum(3, 5)

result = calculate_sum(3, 5)

# Vì calculate_sum có return nên ta có thể dùng result tiếp
print("Nhân đôi kết quả:", result * 2)
Kết quả chạy:
8
Nhân đôi kết quả: 16

1.7. Khi nào nên tạo một hàm?

  • Khi một đoạn code thực hiện một nhiệm vụ có tên rõ ràng.
  • Khi đoạn code đó lặp lại từ hai lần trở lên.
  • Khi chương trình quá dài và cần chia nhỏ.
  • Khi cần kiểm thử riêng từng phần.
Không nên: tạo một hàm vừa nhập dữ liệu, vừa tính toán, vừa ghi file, vừa gửi email, vừa in báo cáo. Một hàm tốt nên tập trung vào một nhiệm vụ chính.

Bài thực hành – Viết hàm tính diện tích hình chữ nhật

Tên file: bt01_rectangle_area.py

  1. Tạo hàm rectangle_area(length, width).
  2. Bên trong hàm tính length * width.
  3. Dùng return để trả kết quả.
  4. Bên ngoài nhập chiều dài và chiều rộng.
  5. Gọi hàm và in kết quả.
# Tạo hàm có hai tham số: length và width
def rectangle_area(length, width):
    # Tính diện tích bằng công thức dài × rộng
    area = length * width

    # Dùng return vì ta muốn gửi kết quả ra ngoài hàm
    return area


# input() luôn trả chuỗi
# Vì cần tính toán nên chuyển sang float
length = float(input("Nhập chiều dài: "))
width = float(input("Nhập chiều rộng: "))

# Gọi hàm và lưu kết quả trả về
result = rectangle_area(length, width)

# Hiển thị kết quả
print(f"Diện tích = {result}")
Ví dụ chạy:
Nhập chiều dài: 5
Nhập chiều rộng: 3
Diện tích = 15.0

2. SCOPE – PHẠM VI BIẾN, LOCAL VÀ GLOBAL

2.1. Scope là gì?

Scope là phạm vi mà một biến có thể được truy cập. Không phải biến nào cũng có thể dùng ở mọi vị trí trong chương trình.

2.2. Biến cục bộ – local variable

Biến được tạo bên trong hàm thường chỉ tồn tại trong hàm đó.

def show_student():
    # student_name được tạo bên trong hàm
    # nên đây là biến cục bộ
    student_name = "An"

    # Dùng được vì đang ở trong phạm vi của hàm
    print(student_name)


show_student()

# Dòng dưới sẽ lỗi nếu bỏ dấu #
# vì student_name không tồn tại ngoài hàm
# print(student_name)
Kết quả:
An

2.3. Biến toàn cục – global variable

Biến được tạo ngoài tất cả hàm được gọi là biến toàn cục. Hàm có thể đọc biến này.

# school_name là biến toàn cục
school_name = "BDU"


def show_school():
    # Hàm có thể đọc biến toàn cục
    print("Trường:", school_name)


show_school()

# Biến toàn cục cũng dùng được ở đây
print("Ngoài hàm:", school_name)
Kết quả:
Trường: BDU
Ngoài hàm: BDU

2.4. Khi nào cần từ khóa global?

Nếu chỉ đọc biến toàn cục thì không cần global. Nếu muốn thay đổi trực tiếp biến toàn cục bên trong hàm, phải khai báo global.

# Biến toàn cục
count = 0


def increase():
    # Báo cho Python rằng count bên dưới
    # là biến count ở ngoài hàm, không phải biến cục bộ mới
    global count

    # Tăng biến toàn cục lên 1
    count += 1


increase()
increase()

print(count)
Kết quả:
2

2.5. Vì sao không nên lạm dụng global?

  • Khó biết hàm nào đã thay đổi dữ liệu.
  • Khó kiểm thử độc lập từng hàm.
  • Dễ sinh lỗi khi dự án lớn.
Cách giải thích dễ hiểu: local giống tài liệu riêng trong một phòng; global giống bảng thông báo chung. Nếu ai cũng sửa bảng chung thì rất khó kiểm soát thay đổi.
Khuyến nghị: ưu tiên truyền dữ liệu vào hàm qua tham số và lấy dữ liệu ra bằng return thay vì dùng global.

3. THAM SỐ VÀ ĐỐI SỐ

3.1. Parameter và argument khác nhau thế nào?

Parameter là tên biến trong phần định nghĩa hàm. Argument là giá trị thật được truyền vào khi gọi hàm.

# name và age là parameter
def introduce(name, age):
    print(name, age)


# "An" và 18 là argument
introduce("An", 18)
Kết quả:
An 18

3.2. Positional arguments

Giá trị được gán cho tham số theo vị trí.

def introduce(name, age):
    print("Tên:", name)
    print("Tuổi:", age)


# "An" đứng vị trí thứ nhất → gán cho name
# 18 đứng vị trí thứ hai → gán cho age
introduce("An", 18)
Nếu gọi introduce(18, "An") thì chương trình vẫn có thể chạy nhưng dữ liệu bị gán sai ý nghĩa.

3.3. Keyword arguments

Keyword arguments truyền dữ liệu theo tên tham số.

def introduce(name, age):
    print("Tên:", name)
    print("Tuổi:", age)


# Vì ghi rõ age= và name=
# nên thứ tự khi truyền không còn quan trọng
introduce(age=18, name="An")
Kết quả:
Tên: An
Tuổi: 18

3.4. Default parameter

Tham số mặc định giúp hàm có một giá trị sẵn nếu người gọi không truyền.

# message có giá trị mặc định là "Xin chào"
def greet(name, message="Xin chào"):
    print(f"{message} {name}")


# Không truyền message → dùng giá trị mặc định
greet("An")

# Có truyền message → giá trị mới ghi đè mặc định
greet("Bình", "Chào buổi sáng")
Kết quả:
Xin chào An
Chào buổi sáng Bình

3.5. *args – số lượng đối số vị trí linh hoạt

*args dùng khi chưa biết trước người gọi sẽ truyền bao nhiêu đối số vị trí.

# *numbers gom tất cả đối số vị trí thành tuple
def total(*numbers):
    # sum() cộng toàn bộ phần tử trong tuple
    return sum(numbers)


print(total(1, 2))
print(total(1, 2, 3, 4, 5))
Kết quả:
3
15

3.6. **kwargs – số lượng đối số theo tên linh hoạt

**kwargs gom các cặp ten=gia_tri thành dictionary.

# **info nhận dữ liệu dạng key=value
def show_info(**info):
    # info là dictionary
    for key, value in info.items():
        print(f"{key}: {value}")


show_info(
    name="An",
    age=18,
    city="Ca Mau"
)
Kết quả:
name: An
age: 18
city: Ca Mau

3.7. Khi nào dùng loại nào?

LoạiKhi nên dùng
PositionalÍt tham số, thứ tự rõ
KeywordNhiều tham số, muốn dễ đọc
DefaultCó giá trị thường dùng
*argsSố lượng đối số vị trí thay đổi
**kwargsThông tin linh hoạt dạng tên=giá trị

4. RETURN – TRẢ KẾT QUẢ TỪ HÀM

4.1. Vì sao cần return?

print() chỉ hiển thị dữ liệu. return đưa dữ liệu ra khỏi hàm để chương trình có thể lưu, tính tiếp hoặc truyền sang hàm khác.

# Hàm chỉ hiển thị
def show_sum(a, b):
    print(a + b)


# Hàm trả giá trị
def calculate_sum(a, b):
    return a + b


show_sum(3, 5)

# calculate_sum trả về 8
# nên ta lưu được vào result
result = calculate_sum(3, 5)

# Có thể tiếp tục dùng result
print("Nhân đôi:", result * 2)
Kết quả:
8
Nhân đôi: 16

4.2. return làm hàm kết thúc ngay

def check_number(number):
    # Nếu số âm, trả kết quả ngay
    if number < 0:
        return "Số âm"

    # Chỉ chạy nếu điều kiện trên không return
    return "Không âm"


print(check_number(-5))
print(check_number(8))
Kết quả:
Số âm
Không âm

4.3. Hàm không có return rõ ràng sẽ trả về None

def hello():
    print("Xin chào")


result = hello()

# Vì hàm không return nên result nhận None
print("Giá trị trả về:", result)
Kết quả:
Xin chào
Giá trị trả về: None

4.4. Trả về nhiều giá trị

def calculate(a, b):
    # Python gom 3 giá trị thành một tuple
    return a + b, a - b, a * b


# Giải nén tuple thành 3 biến
sum_value, diff_value, product = calculate(10, 3)

print("Tổng:", sum_value)
print("Hiệu:", diff_value)
print("Tích:", product)
Kết quả:
Tổng: 13
Hiệu: 7
Tích: 30

5. DOCSTRING VÀ TYPE HINTS

5.1. Docstring là gì?

Docstring là phần mô tả chính thức của hàm, class hoặc module. Nó được đặt ngay sau dòng định nghĩa.

def add(a, b):
    """
    Trả về tổng của hai số.
    """
    return a + b

5.2. Docstring đầy đủ

def rectangle_area(length, width):
    """
    Tính diện tích hình chữ nhật.

    Args:
        length: Chiều dài.
        width: Chiều rộng.

    Returns:
        Diện tích hình chữ nhật.
    """
    return length * width

5.3. Docstring khác comment thế nào?

Comment #Docstring
Giải thích cho người đọc codeMô tả chính thức hàm/module/class
Không được help() đọcCó thể xem bằng help()

5.4. Type hints là gì?

Type hints là cách ghi chú kiểu dữ liệu mong đợi cho tham số và kiểu dữ liệu trả về.

# a: int nghĩa là a dự kiến là số nguyên
# b: int nghĩa là b dự kiến là số nguyên
# -> int nghĩa là hàm dự kiến trả về số nguyên
def add(a: int, b: int) -> int:
    return a + b


print(add(4, 6))
Kết quả:
10

5.5. Type hints không ép kiểu

Python vẫn là ngôn ngữ động. Type hints giúp IDE và công cụ kiểm tra hiểu ý định của lập trình viên, nhưng Python không tự chặn hoàn toàn việc truyền sai kiểu.

5.6. Type hints với list

# scores là danh sách các số thực
# Hàm trả về float
def average(scores: list[float]) -> float:
    # sum() cộng tất cả điểm
    # len() đếm số lượng điểm
    return sum(scores) / len(scores)


result = average([7.5, 8.0, 6.5])

print(f"{result:.2f}")
Kết quả:
7.33

5.7. Khi nào nên dùng type hints?

  • Dự án có nhiều file.
  • Làm việc nhóm.
  • Hàm có nhiều tham số.
  • Muốn IDE cảnh báo lỗi sớm.

6. LAMBDA, MAP() VÀ FILTER()

6.1. Lambda là gì?

Lambda là cách tạo hàm ngắn, thường không cần đặt tên bằng def.

# lambda x: x ** 2
# x là tham số
# x ** 2 là biểu thức được trả về
square = lambda x: x ** 2

print(square(5))
Kết quả:
25

6.2. Lambda tương đương def

def square(x):
    return x ** 2

6.3. Khi nào nên dùng lambda?

  • Hàm rất ngắn.
  • Chỉ dùng một lần.
  • Dùng kèm map(), filter(), sorted().
Nếu logic dài hoặc có nhiều bước, nên dùng def vì dễ đọc hơn.

6.4. map()

map() áp dụng một hàm cho từng phần tử.

# Danh sách ban đầu
numbers = [1, 2, 3, 4]

# map() lấy từng số và đưa vào lambda
# lambda trả lại bình phương của số đó
# list() chuyển kết quả map thành danh sách
squares = list(
    map(lambda x: x ** 2, numbers)
)

print(squares)
Kết quả:
[1, 4, 9, 16]

6.5. filter()

filter() giữ lại những phần tử mà hàm điều kiện trả về True.

scores = [4, 5, 7, 8, 3, 9]

# Với mỗi score:
# nếu score >= 5 thì lambda trả True
# filter() giữ lại score đó
passed_scores = list(
    filter(lambda score: score >= 5, scores)
)

print(passed_scores)
Kết quả:
[5, 7, 8, 9]

6.6. So sánh map/filter với comprehension

Mục đíchmap/filterComprehension
Bình phươngmap(lambda x: x**2, data)[x**2 for x in data]
Lọc điểmfilter(lambda x: x>=5, data)[x for x in data if x>=5]
Với sinh viên mới học, nên cho các bạn hiểu map/filter trước, sau đó so sánh với comprehension để biết cách nào dễ đọc hơn.

7. MÔ-ĐUN VÀ IMPORT

7.1. Mô-đun là gì?

Mỗi file Python .py có thể được xem là một mô-đun. Mô-đun thường chứa các hàm hoặc class cùng chủ đề.

7.2. Vì sao cần module?

  • Không để một file quá dài.
  • Nhóm chức năng liên quan.
  • Tái sử dụng code.
  • Dễ bảo trì.

7.3. import module

# Nạp module math có sẵn của Python
import math

# Vì import cả module nên phải gọi theo dạng math.ten_ham
print(math.sqrt(16))
Kết quả:
4.0

7.4. from ... import ...

# Chỉ lấy riêng hàm sqrt từ module math
from math import sqrt

# Vì đã import trực tiếp nên không cần viết math.
print(sqrt(16))
Kết quả:
4.0

7.5. as – bí danh

# Đặt bí danh m cho module math
import math as m

# Dùng m thay cho math
print(m.sqrt(16))
Kết quả:
4.0

7.6. Module tự tạo

Cấu trúc:

project/
├── calculator.py
└── main.py

calculator.py

# Hàm cộng
def add(a, b):
    return a + b


# Hàm trừ
def subtract(a, b):
    return a - b

main.py

# Import module do chính ta tạo
import calculator

# Gọi hàm thông qua tên module
print(calculator.add(10, 3))
print(calculator.subtract(10, 3))
Kết quả:
13
7
Không nên dùng from module import * vì khó biết tên nào được import từ đâu.

8. PACKAGE VÀ CẤU TRÚC DỰ ÁN

8.1. Package là gì?

Package là thư mục chứa nhiều module liên quan.

my_project/
├── main.py
└── utils/
    ├── __init__.py
    ├── math_utils.py
    └── text_utils.py

8.2. Ý nghĩa từng file

FileVai trò
main.pyĐiểm bắt đầu chạy chương trình

Bài 1. Hàm tính điểm trung bình

Tên file: bt01_average.py

  1. Tạo hàm average(scores).
  2. scores là list các số thực.
  3. Dùng sum(scores) và len(scores).
  4. Dùng return.
  5. Bên ngoài gọi hàm và in kết quả.
# scores: list[float] giúp người đọc biết
# hàm mong đợi một danh sách số thực
def average(scores: list[float]) -> float:
    # sum(scores) cộng toàn bộ điểm
    total = sum(scores)

    # len(scores) đếm số lượng điểm
    count = len(scores)

    # Trả trung bình ra ngoài hàm
    return total / count


# Danh sách dữ liệu mẫu
scores = [7.0, 8.0, 9.0]

# Gọi hàm và lưu kết quả
result = average(scores)

# :.2f hiển thị 2 chữ số thập phân
print(f"Điểm trung bình: {result:.2f}")
Kết quả:
Điểm trung bình: 8.00

Bài 2. Hàm xếp loại

Tên file: bt02_classify.py

  1. Tạo hàm classify(score).
  2. Nếu score >= 8 return "Giỏi".
  3. Nếu >= 6.5 return "Khá".
  4. Nếu >= 5 return "Trung bình".
  5. Còn lại return "Chưa đạt".
def classify(score: float) -> str:
    # Kiểm tra mức cao nhất trước
    if score >= 8:
        return "Giỏi"

    # Nếu không đạt Giỏi, kiểm tra Khá
    if score >= 6.5:
        return "Khá"

    # Nếu không đạt Khá, kiểm tra Trung bình
    if score >= 5:
        return "Trung bình"

    # Nếu không thuộc các trường hợp trên
    return "Chưa đạt"


print(classify(7.2))
